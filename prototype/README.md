# HotkeyStats 原型（macOS · Swift · AppKit）

菜单栏常驻的热键使用统计工具：只统计带修饰键（⌘/⌥/⌃/Fn）的组合键，不记录普通打字，数据仅保存在本机。

## 构建

```bash
./build.sh
```

产物：`dist/HotkeyStats.app`（已 ad-hoc 签名，`LSUIElement` 为真，无 Dock 图标）。

HotkeyStats 正在运行时脚本会停止，避免换掉正在使用的应用包。请先从菜单退出，再重新构建。编译或签名失败时，上一份 `dist/HotkeyStats.app` 会保留。

## 运行与授权

1. `open dist/HotkeyStats.app` 启动，菜单栏出现黑绿图标；
2. 菜单显示无权限时，点击“打开输入监控设置…”并允许系统授权，在 **系统设置 → 隐私与安全性 → 输入监控** 勾选 HotkeyStats.app；
3. 授权后点击“重新检查权限”；如果系统要求重新启动，请退出后重新打开。任意应用里按 `⌘C`、`⌘⇧3` 等组合键，点菜单栏图标即可看到 Top 5 和今日统计；
4. 「打开统计窗口」可查看全量数据（组合键 / 总次数 / 今日 / 最近使用），支持清空。

## 目录结构

```
Info.plist               应用包标识、LSUIElement
Sources/HotkeyStats/
├── main.swift            入口 + AppDelegate（权限检测、定时落盘）
├── Models.swift          数据模型、组合键归一化解析、keycode→可读名
├── EventTapMonitor.swift CGEventTap 全局监听（listen-only）
├── StatsStore.swift      内存聚合 + JSON 持久化（Application Support）
├── MainWindow.swift      主统计窗口（NSTableView）
└── StatusBar.swift       菜单栏（Top 5 快捷视图 + 今日统计）
```

## 数据位置

`~/Library/Application Support/HotkeyStats/records.json`

落盘时机：退出时 / 每 5 分钟 / 每新增 50 条记录。

## 注意事项

- 用 `open dist/HotkeyStats.app` 启动，让辅助功能和输入监控授权绑定到 HotkeyStats.app，而不是终端或 IDE。每次 ad-hoc 重新编译后签名哈希会变，系统可能要求重新勾选。旧裸二进制上的授权不会自动转到这个应用包；
- 若统计中途失效，程序会自动重启用事件监听（tap 自愈），无需手动干预；
- 本原型为 M0 版本，后续路线见 [`../docs/设计文档.md`](../docs/设计文档.md) 与 [`../docs/功能清单.md`](../docs/功能清单.md)。

## 原型修复与验证

- 按键名称使用明确的 macOS ANSI 物理键码表，不随输入法或键盘布局变化；字符分类复用同一映射。
- 统计窗口首次打开前的数据通知不会访问界面；关闭后保留窗口以便复用。
- 数据格式升级为 v2。首次读取 v1 时，先在数据目录写入 `records-v1-backup-<UUID>.json`，再根据键码和修饰键修正名称、合并计数并过滤普通输入。历史记录中已混合的不同键位次数无法准确拆分。
- 备份失败或数据版本高于当前支持版本时，不覆盖原文件。

运行回归检查：

```bash
./test.sh
```

检查覆盖全部键名和修饰键过滤、迁移与最早/最近时间、备份失败、未知版本、重复加载、满 50 次保存、保存失败、清空，以及未打开窗口时的数据通知。日志模块要求区域、函数和行覆盖率都是 100%。构建脚本检查运行中的进程、缺少清单、替换失败和成功替换。这些检查使用临时目录，不写入实际统计文件，也不替换 `dist/HotkeyStats.app`。

手工验收：启动后先使用快捷键，再打开统计窗口；关闭并重新打开窗口；退出重启后确认数据保留。这些操作需要在有监听权限的桌面会话中完成。

## 应用运行日志

本地项目构建的运行日志保存在项目根目录 `logs/YYYY-MM-DD.log`，使用北京时间。编译时源码在运行机器上不存在时，安装版回退到 `~/Library/Logs/HotkeyStats/`；可通过绝对路径环境变量 `HOTKEYSTATS_LOG_DIR` 指定目录。日志包含启动退出、重复实例、权限与暂停状态变化、监听创建/停止/恢复、存储加载/保存/迁移结果和登录项操作。相同状态的周期检查不重复输出，DEBUG 日志额外输出实际计数的快捷键名称，例如 `Hotkey counted: "⌘C"`；不记录普通输入、长按重复事件或统计明细。

日志异步追加，保留 30 天，每天最多 10 MiB；达到上限后当天停止追加。写入失败时回退系统日志。根目录 `logs/` 仅保存程序自动生成的运行调试日志，不保存开发记录，日志不纳入 Git。

运行 `./prototype/test-logger.sh` 可独立执行日志测试并显示 LLVM 覆盖率；`./prototype/test.sh` 同时执行原型回归与日志测试。

## v1.0 新增交互

- 重复启动由单实例锁阻止并通知已有实例打开窗口；直接运行二进制也受互斥保护。
- 菜单可暂停或继续，暂停停止监听，退出重启保留暂停偏好。
- 长按产生的自动重复 keyDown 不计数，松开重新按下才再次计数。
- 菜单图标、提示和统计窗口显示统计中、已暂停、无权限或监听失败；每 5 秒及菜单展开时检查权限。
- 累计次数、今日次数、最近使用支持表头升降序，刷新保留排序；无数据时显示对应状态说明。
- 有效应用包可切换登录启动，状态以系统服务为准；默认不注册，需要批准时通过菜单进入系统登录项设置。直接启动二进制不提供此功能。
- `./test-runtime.sh` 验证状态、暂停持久化、跨进程互斥、符号链接拒绝、排序及模拟登录服务，并报告模块覆盖率。测试不修改真实登录项。

用户于 2026-11-07 确认桌面验收通过：权限撤销与恢复、登录后自动启动、暂停重启保持、重复启动唤起窗口，以及不同应用中的快捷键计数。此结论来自用户实测，适用于本次测试环境。 系统审批特殊状态、应用移动及首次并发启动竞态尚无单独实测结论。

## DMG 打包

先运行 `./build.sh`，再运行 `./package-dmg.sh`。安装映像输出至 `dist/HotkeyStats-<版本>-<架构>.dmg`，包含应用及 Applications 快捷入口；打开后将应用拖入“应用程序”。脚本检查应用签名及映像完整性后才替换产物。

当前产物仅为本地 ad-hoc 签名，未经过 Apple 公证；打包不会改变应用的权限要求和既有验收状态。

## 应用图标

应用使用黑底薄荷绿 Command 与统计图形图标。源图及多尺寸资源位于 `Resources/`，构建时将 `AppIcon.icns` 放入应用包并通过 `CFBundleIconFile` 引用。菜单栏使用同款彩色图标：统计中不加角标，暂停为橙色 Ⅱ，无权限为橙色 !，监听失败为红色 ×；悬停提示和辅助功能标签显示状态。

## 保存失败与质量检查

保存失败时，菜单顶部显示警告及“重试保存”；保存成功自动清除警告。未知数据版本和迁移备份失败时保持保护状态，重试不会覆盖原文件。

`test-runtime.sh` 对 Runtime、RecordOrdering、LoginLaunch 策略模块强制行、区域和函数覆盖率 100%；日志模块同样强制 100%。真实登录项操作与提示窗口位于 LoginSystemAdapter.swift，由桌面验收负责，不计入策略覆盖率；不代表全项目覆盖率 100%。
