# HotkeyStats

一个使用 Swift、AppKit 和 CoreGraphics 编写的 macOS 菜单栏快捷键使用统计工具。

它用于了解自己常用哪些快捷键、每个组合使用了多少次，以及今天的使用情况。当前处于原型阶段。

## 功能

- 全局只读监听组合键，不拦截或修改键盘事件。
- 菜单栏展示累计使用最多的 5 个快捷键、今日总次数和组合键种类数。
- 统计窗口展示组合键、累计次数、今日次数和最近使用时间，按累计次数降序排列。
- 支持手动刷新和清空统计，清空前会要求确认。
- 统计结果仅保存到本机 JSON 文件，当前实现无网络通信代码。
- 过滤无修饰键的普通输入，以及仅 Shift 修饰的字母、数字和标点输入；保留 Shift + 功能键组合。

> 记录的是按键组合的发生次数，不能判断对应功能是否成功执行，也不能判断快捷键是否发生冲突。

## 环境要求

- macOS；设计目标为 macOS 14 及以上。
- Xcode 或 Xcode Command Line Tools，提供 `swiftc` 和系统 SDK。
- 系统键盘监听授权；程序启动时提供权限提示。

当前实现依赖 macOS 原生框架，只在 macOS 上构建和运行。Windows 版安排在 v1.4，见 [功能清单](docs/功能清单.md)。

## 构建与启动

在项目根目录执行：

```bash
./prototype/build.sh
open ./prototype/dist/HotkeyStats.app
```

构建脚本使用 Swift 5 语言模式编译，并执行本地 ad-hoc 签名。产物是 `prototype/dist/HotkeyStats.app`（`LSUIElement` 为真，无 Dock 图标）。尚未进行 Developer ID 签名和公证。HotkeyStats 正在运行时构建会停止；编译或签名失败时，上一份应用包会保留。请先从菜单退出，再重新构建。

启动后，顶部菜单栏显示 **⌨︎** 图标，不显示 Dock 图标。

### 首次授权

1. 按启动提示进入「系统设置 → 隐私与安全性 → 辅助功能」，添加并启用 HotkeyStats.app。
2. 若仍无法监听，请在「输入监控」中勾选同一个 HotkeyStats.app。当前代码使用 `CGPreflightListenEventAccess()` 检查监听访问权限，但提示界面仍指向「辅助功能」。
3. 授权后退出并重新启动程序。

菜单栏图标显示 **⌨︎⚠︎** 表示启动时未获得所需访问权限或监听创建失败。每次 ad-hoc 重新编译后签名哈希会变，系统可能要求重新勾选 HotkeyStats.app。旧裸二进制上的授权不会自动转到这个应用包。

## 使用方法

点击菜单栏 **⌨︎**：

- 查看累计 Top 5 和今日总量。
- 选择「打开统计窗口…」查看全部组合键。
- 选择「退出 HotkeyStats」正常退出并保存数据。

统计在后台持续进行，不需要一直打开统计窗口。窗口中的「刷新」可重新读取当前内存统计；「清空统计」会删除当前全部统计，操作不可恢复。

## 验证统计是否正常

1. 在文本编辑器中选中文字。
2. 打开统计窗口，记下 `⌘C` 的累计次数和今日次数。
3. 回到编辑器，分开按 3 次 `⌘C`，每次松开按键。
4. 回到统计窗口，确认两项次数都增加 3。
5. 输入普通字母、大写字母、数字和标点，确认未产生相应普通输入记录。
6. 关闭统计窗口，继续使用快捷键，再打开窗口，确认数据更新且程序正常。
7. 从菜单栏正常退出并重新启动，确认统计保留。

切换应用时使用的快捷键也会被统计。长按按键产生的系统重复事件目前会计入次数，因此验证时应分次按下。

### 自动回归检查

```bash
./prototype/test.sh
```

覆盖键码映射、输入过滤、历史迁移、备份失败、未知版本、重复加载、保存与清空、未打开窗口时的数据通知，以及构建脚本分支。日志模块的覆盖率必须是 100%。迁移和构建检查使用临时目录，不改写实际统计文件，也不替换已构建的应用包；全局监听权限和窗口交互仍需手工验证。

## 数据存储

统计文件：

```text
~/Library/Application Support/HotkeyStats/records.json
```

保存时机：正常退出、每 5 分钟，以及每累计 50 次新记录。异常退出可能丢失尚未保存的部分计数。

当前格式版本为 **v2**。首次加载 v1 数据时，会先在同一目录生成 `records-v1-backup-<UUID>.json`，再按保存的键码和修饰键修正组合键名称、合并计数并过滤普通输入。备份失败或遇到未知数据版本时，不覆盖原文件。

旧版已将不同物理键混合到同一条记录的次数无法精确拆分；验证准确性时，应以修复后新增计数为准。

## 当前限制与后续规划

- 键名按 ANSI 物理键位显示，不随当前输入法或键盘布局变化，未覆盖键可能显示为 `Key(n)`。
- 按修饰键规则识别组合，无法在语义上区分快捷键与所有文本输入场景，例如 Option 参与的字符输入仍可能被统计。
- 尚不支持按应用归属、历史趋势、时间筛选、忽略名单和 CSV 导出。
- 本地构建产物是 ad-hoc 签名的 HotkeyStats.app。尚未做 Developer ID 签名、公证分发和自动更新。
- Windows 版放在 v1.4，对齐 v1.0 的日常统计；v1.0–v1.3 只做 macOS。

更多规划见 [设计文档](docs/设计文档.md) 和 [功能清单](docs/功能清单.md)。v1.0–v1.2 的成品界面图示见 [原型图](docs/原型图/README.md)。
