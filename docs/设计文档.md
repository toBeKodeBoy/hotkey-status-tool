# 热键统计工具（HotkeyStats）设计文档

> 版本 v0.1 ｜ 当前平台 macOS 14+ ｜ 技术栈 Swift + AppKit + CoreGraphics ｜ 2026-10-24
>
> Windows 版放在 v1.4，见 [功能清单](功能清单.md)。v1.0–v1.3 不改现有 macOS 技术栈。

---

## 1. 产品定位

一款**本地隐私优先**的 macOS 热键使用统计工具。它只回答一个问题：

> 「我（和这台电脑上的应用）实际在用哪些快捷键？用得最多的是什么？」

不做宏、不做按键改写、不联网——只记录、统计、展示。

### 1.1 目标用户

- 重度键盘用户（开发者、文字工作者），想优化自己的快捷键习惯；
- 效率工具用户，想排查「某个快捷键到底被哪个场景占用、多久用一次」；
- 团队效率调研者，想导出匿名化统计数据。

### 1.2 核心原则

| 原则 | 说明 |
|---|---|
| **只记热键，不记打字** | 仅记录带修饰键（⌘/⌥/⌃/Fn）的组合键，纯文本输入一概不采集，从架构上规避键盘记录器嫌疑 |
| **数据不出本机** | 无任何网络权限请求；数据仅存 `~/Library/Application Support/HotkeyStats/` |
| **轻量常驻** | 菜单栏形态，无 Dock 图标，内存目标 < 50 MB，CPU 闲时 0% |

## 2. 功能清单

### P0（原型已实现）

- 全局监听热键按下（CGEventTap，listen-only，不拦截不修改）
- 组合键解析为可读文本（如 `⌘⇧3`、`⌃⌥Space`）
- 统计维度：总次数、今日次数、最近使用时间
- 菜单栏快捷视图（Top 5 热键 + 今日总量 + 快捷键总数）
- 主窗口：表格展示全量数据，支持按次数排序、手动刷新、清空统计
- JSON 持久化，重启后数据保留

### P1（下一迭代）

- 按前台应用归属统计（`NSWorkspace` 获取前台 app，标注「⌘T — 记录于 Safari」）
- 7/30 天趋势图（Swift Charts）
- 冲突提示：同一组合键在多应用中高频出现时给出提醒
- 菜单栏实时排名（今日 Top 1 变化时更新图标旁文字）

### P2（远期）

- 导出 CSV / JSON
- 忽略名单（指定应用不统计）
- 统计窗口内按应用、按时间段筛选
- 匿名化报告生成

## 4. 关键技术设计

### 4.1 全局按键监听：CGEventTap（listen-only）

```swift
CGEventTapCreate(
    .cgSessionEventTap,        // 会话级
    .headInsertEventTap,       // 插队但不吞事件
    .listenOnly,               // ★ 关键：只听不拦，不影响任何按键
    [.keyDown],                // 只关心 keyDown
    callback, nil)
```

- **listenOnly 是本工具的合规底线**：不吞事件、不伪造事件，行为上等价于「旁路观察」。
- 需要用 `CGEventTapEnable` 在回调里对 `tapDisabledByTimeout/ByUserInput` 做自愈重启。

### 4.2 权限模型

| 能力 | 所需权限 | 说明 |
|---|---|---|
| CGEventTap | **辅助功能（Accessibility）** | 系统设置 → 隐私与安全性 → 辅助功能，勾选本应用 |
| 前台应用识别（P1） | 无需额外权限 | `NSWorkspace.shared.frontmostApplication` |
| App Store 分发 | 不可行 | 监听全局键盘事件的 App 会被 MAS 拒审，本项目走独立分发（Developer ID 签名 + 公证） |

原型阶段用 **ad-hoc 签名**（`codesign -s -`）即可获得辅助功能授权资格；正式分发前必须换 Developer ID 并公证，否则 Gatekeeper 拦截。

### 4.3 组合键归一化

同一物理组合在不同按下顺序下产生不同 flags 序列，需归一化：

1. 从 `CGEventGetFlags` 提取 mask：`maskCommand / maskAlternate / maskControl / maskShift / maskSecondaryFn`；
2. 忽略 `maskNonCoalesced` 与 CapsLock 状态位；
3. **区分打字与热键**：`⌘⇧S` 与 `⌘S` 是不同热键，Shift 照常参与归一化；唯一例外是「Shift 为**唯一**修饰键 + 字符类主键（字母/数字/标点）」——如输入大写字母 `⇧A`，这是打字不是热键，**在监听层直接丢弃**（既不计入统计也不进内存）；Shift 与功能键的组合（`⇧Tab`、`⇧F1`）正常记录；
4. 归一化结果 = `flags 排序串 + keyName`，作为统计主键，如 `⌃⌥⌘Space`。

### 4.4 数据模型（存储层 JSON Schema）

```json
{
  "schemaVersion": 1,
  "records": [
    {
      "combo": "⌘⌥T",
      "keycode": 17,
      "flagsRaw": 1310724,
      "count": 238,
      "todayCount": 12,
      "todayDate": "2026-10-24",
      "firstSeen": "2026-10-24T09:12:33+08:00",
      "lastSeen": "2026-10-24T19:48:02+08:00"
    }
  ]
}
```

- 落盘时机：退出时 + 每 5 分钟 + 记录数每新增 50 条，避免频繁 IO；
- `todayCount/todayDate` 惰性重置：跨天首次读取时归零。

### 4.5 隐私与合规

- 仅采集修饰键组合（设计 4.3 的过滤在监听层完成，纯按键**不进入内存模型**，即使被取证也无法还原输入内容）；
- 无网络代码路径，`entitlements` 不申请 `com.apple.security.network.*`；
- P1 引入应用归属后，导出数据默认剥离应用名（可开关）。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 辅助功能未授权 | EventTap 为 nil，无数据 | 启动时检测并引导跳转系统设置；菜单栏图标变警示态 |
| 系统超时禁用 tap | 统计中断 | 回调内捕获 `tapDisabledBy*` 自动重启用 |
| keycode→字符映射不全 | 显示为 `Key(45)` | 覆盖常用键表 + P1 换 `UCKeyTranslate` 走当前键盘布局 |
| 被安全软件误判为键盘记录器 | 安装受阻 | listen-only + 不采集纯按键 + 开源代码自证 |
| M 系列芯片能耗 | 常驻耗电 | 无轮询、纯事件驱动，落盘合并批量写 |

## 6. 迭代路线

分版功能、数据迁移和验收见 [功能清单](功能清单.md)。应用版本与 `records.json` 的 `schemaVersion` 分开编号。

| 阶段 | 版本 | 内容 | 验收标准 |
|---|---|---|---|
| M0（当前原型） | — | 全局监听 + 统计 + 菜单栏/主窗口 | 授权后任意热键按下 1 秒内计入统计，重启数据不丢 |
| M0 收口 | v1.0 | 应用包、单实例、暂停、按住只计一次、权限状态 | 可以日常常驻，暂停后不再计数 |
| M1 | v1.1 / v1.2 | v1.1 前台应用归属与忽略名单；v1.2 趋势、时间筛选、冲突提示和布局键名 | v1.1 能回答「⌘T 在哪些应用里被用了多少次」 |
| M2 | v1.2 / v1.3 | 冲突与键名放在 v1.2；导出与匿名报告放在 v1.3 | 匿名导出报告可用 |
| M3 | v1.3 | Developer ID 公证分发 + 可关闭的 Sparkle 更新检查 | 非 App Store 独立分发可用；更新检查不上传统计 |
| Windows 首版 | v1.4 | 系统托盘、只读低级键盘钩子、与 v1.0 对齐的计数和同一套 schema | 在 Windows 上可日常统计；暂停后按键仍原样送达当前应用 |
